## Scope

Audit the implemented package against [the final API contract](004-public-api-target.md)
and its retained/replaced/removed matrix. Consolidate exports and documentation.
This approves removal of remaining obsolete CurrentFileSort, AvailableTagSort,
TagMatchMode aliases when no retained public signature needs them; convert CLI
internal annotations to local types. No additional method removals or renames.

Verify all four constructors and detail/query/result types have one documented
import path, clear return types, argument errors, eager/lazy boundaries and
bounds. Keep query factories in archiver.query and query classes re-exported
from archiver. Retain existing domain/error/helper exports except those listed
as retired. Keep three pandas adapters separate and functional.

Audit tracked public notebooks, examples, tests, and docs for executable
obsolete APIs, including the 004.4 tutorial gap. Update current tutorials or
explicitly label historical artifacts and their frozen-version requirement.
Preserve archival plan records. Do not inspect or modify private notebooks.
Update docs/query-grammar.md, README and design narrative for the actual result.

Create a single `docs/catalog-api.md` reference documenting every public
`Catalog` method, including constructors, lifecycle methods, query entry
points, retained reads, and mutations. Each entry must give the implemented
signature (including parameter types and defaults), return type, and a short
description. Verify coverage against the actual public `Catalog` surface after
cleanup and link the reference from README. This provides a reference for later
archive-layer design; archive-layer design and implementation remain out of scope.

Duplicate group/member streaming approved by Plan 004.4.1 remains supported;
the boundary below excludes additional, unapproved streaming surfaces.
