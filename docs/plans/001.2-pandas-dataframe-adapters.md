## Relationship to Plan 001

Plan 001 provides typed catalog query results. Plan 001.1 adds typed streaming history results. This subplan adds a pandas-specific adapter layer for exploring those results as tables without placing pandas behavior on `Catalog` or domain dataclasses.

It does not change the catalog schema, scan behavior, query semantics, or typed query APIs.

## Goal

Provide consistent, convenient DataFrame conversion for current observations, historical observations, and scan history.

## Public API

The `archiver.pandas` module provides:

- `current_files_frame(observations)`
- duplicate_groups_frame(groups)
- `observation_history_frame(observations)`
- `scan_history_frame(scans)`

Each function accepts an iterable of the corresponding typed domain object and returns a flat `pandas.DataFrame`. Passing a streaming history iterator intentionally materializes it, because a DataFrame is an in-memory table.

## Column contract

- Current-file rows expose location, root path, relative path, content algorithm and digest, size, and mtime.
- Duplicate-group rows add 1-based `group_id` and `group_size` before the current-file columns.
- Historical-observation rows additionally expose scan ID, status, start time, and completion time.
- Scan-history rows expose scan and location fields.
- All converters return stable named columns for empty input.

Nested domain objects are flattened to scalar or string table values. Relative paths use POSIX text; location roots use their string path representation.
