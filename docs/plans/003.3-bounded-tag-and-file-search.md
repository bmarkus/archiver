## Goal

Make active content tags useful for bounded catalog exploration without changing tag mutation semantics, source files, or the persistent schema.

This record defines the shared design boundary. Detailed interfaces, command behavior, edge cases, tests, and implementation decisions belong to the implementation subplans:

1. [003.3a — Multi-Tag Content Search](003.3a-bounded-tag-query-apis.md)
2. [003.3b — Tag-Aware Current-File Search](003.3b-tag-aware-file-and-content-cli.md)
3. [003.3c — Available Tag Vocabulary](003.3c-tag-vocabulary-cli.md)

Implement and validate one subplan at a time. Do not begin the next subplan automatically.

## Shared semantics

- Searches use active assertions only; retracted assertions never match.
- A content identity matches a tag once even when multiple provenance sources actively assert it.
- Tag matching is content-based. Paths remain observations scoped to a location and its latest successful scan.
- Query results and previews are explicitly bounded and deterministically ordered. Complete totals describe all matches, not only displayed rows.
- Limits are applied in SQLite before file, content, path, or tag preview rows are materialized. An explicit all-tags display may materialize all distinct active tags only for already bounded parent rows.
- Existing `Catalog.search_current_files()` and single-tag `Catalog.search_tagged_content()` APIs remain compatible. Richer projections use new APIs.
- All operations are read-only for source files and catalog metadata, including invalid-input and query-failure paths.

## Persistence and presentation boundary

- Schema version remains 2; no migration is introduced.
- CLI tables use deterministic standard-library formatting, stable non-interactive terminal-width fallback, shortened display digests, and no color or third-party table dependency.

## Non-goals

Exclude automatic classification, tag mutation changes, tag merge/history policy, saved searches, JSON output, path regex, fuzzy matching, pagination tokens, GUI behavior, archive management, and managed filesystem operations.
