## Scope

Earlier owning subplans already migrate duplicate, file, content and vocabulary
CLI branches. Audit their final consistency and close integration gaps without
adding new command syntax or output formats.

CLI builds public queries for collection/search reads. It continues to call
retained lifecycle/mutation/exact/history APIs where appropriate. It must not
import private compiler modules, access SQLite connections, or reconstruct
removed search wrappers. Renderers take typed rows plus explicit totals.

Preserve summary-first duplicate output, default row/member/tag limits,
optional all-tags behavior, full-identity selection versus abbreviated display,
sort/reverse ties, totals, no-scan/empty cases, tag/provenance option validation,
regex errors before opening, fallback/narrow terminal widths and exit codes.
No new query vocabulary or general rendering framework is authorized.
